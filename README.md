## Как запустить

1. Откройте решение `terminal-project.sln` в Visual Studio 2022
2. Нажмите F5 для запуска

## Поддерживаемые команды

1. help - Выводит список доступных команд.
2. exit - Завершает работу программы.
3. ls -  Показывает содержимое текущей директории.
4. cd - Переходит в другую директорию.
5. touch - Создаёт новый файл в текущей директории.
6. mkdir - Создаёт новую директорию.
7. cat - Показывает содержимое текстового файла.
8. edit - Изменяет содержимое файла. 
9. rm - Скрывает файл или директорию вместо настоящего удаления.
10. restore - Восстанавливает ранее скрытую сущность.
11. mv - Переименовывает файл или директорию.

## Авторитативные архитектурные решения

1. Свойство скрытости. Внутри класса Entry. Позволяет единообразно скрывать любые файлы и директории через единое поле isHidden.
2. Фильтрация скрытых файлов. В Terminal при выполнении ls. Entry хранит состояние, Terminal управляет логикой отображения.
3. Поиск сущности по имени. В классе Terminal. Централизует логику поиска, упрощает поддержку и модификацию.
4. Хранение текущего пути (cwd). vector<Directory*>. Быстрый доступ к текущей директории через back(), простая навигация по стеку.
5. Переход между директориями. Явное push_back / pop_back в вектор пути. Чёткая и предсказуемая логика для команд cd.
